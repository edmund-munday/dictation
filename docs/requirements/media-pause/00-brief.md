# Brief (Edmund, 2026-10-14 4:13 PM, via parent; verbatim)
When a dictation starts (on hold-to-talk start), if media is currently playing system-wide, send the OS play/pause (media key, NX_KEYTYPE_PLAY via a system-defined CGEvent, or MediaRemote's pause command); when the dictation ends (release or cancel), resume ONLY if we paused it. If nothing was playing, do nothing. Detecting 'is playing': MediaRemote MRMediaRemoteGetNowPlayingApplicationIsPlaying is restricted on macOS 15.4+ for non-entitled apps, so verify on his Mac and use a working route (e.g. the mediaremote-adapter perl approach via /usr/bin/perl, or checking now-playing via the adapter); never blindly toggle play/pause without knowing the state, because that would START paused media. Keep the detection fast (well under 100 ms, don't delay recording start). Add a menu toggle 'Pause media while dictating' (default on). Put the decision logic in DictationCore with tests, and keep the Mac glue thin.
