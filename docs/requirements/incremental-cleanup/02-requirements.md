# Requirements
- R249 Long dictation, background cleanup: while the talk key is held, each finalised sentence (complete, unchanged over two partials) is sent to the gateway once, in the background, without the plugin section. When its reply arrives the panel shows the cleaned sentence in place of the raw one, followed by the raw rest. Pass: panel text during the hold contains the cleaned first sentence; the gateway saw one request per finalised sentence.
- R250 Release on the long path: only the uncleaned tail is sent (one request), and the inserted text is the cleaned sentences followed by the cleaned tail. Don't-send-at-end ([[NOSEND]] on the tail) still suppresses auto-send; spoken punctuation and quote tokens never leak into inserted text. Release-to-insert time is the tail call only. Pass: insert text equals cleaned parts joined with single spaces; exactly one request after release whose user content is only the tail.
- R251 Cross-sentence corrections: if the full raw text has a cross-sentence cue (scratch that, actually I mean, no wait, I mean, sorry, let me start again, start over, numbered-list cues, an unbalanced spoken quote), the release request covers the whole raw text (today's full call) and its reply is inserted as is. Pass: release request user content is the full transcript; insert is that reply.
- R252 Revised sentence: if whisper changes a sentence after it was sent, the stale reply (for the old text) is discarded; the new text is sent once it is finalised again, or goes into the release call. Pass: panel and inserted text never contain the stale cleaned text.
- R253 Cancel mid-dictation (Escape, another key, latch off): in-flight background replies are dropped; nothing is inserted; no request is sent at release; late replies change nothing.
- R254 Short dictation (fewer than 2 finalised sentences sent before release): no background requests; exactly today's behaviour (one release request with the plugin section, same inserted text, plugin commands still route).
- R255 Gateway failure/timeout for a background sentence: that sentence goes into the release call; if the release call fails or times out, the uncleaned part uses local rules and the cleaned sentences are kept. Nothing is lost or duplicated.
- R256 Cost: at most one background request per sentence revision, at most 2 in flight; a long dictation of N sentences with no revisions makes at most N-1 background requests plus 1 release request.
- R257 Latency bench (opt-in, Mac): replaying tests/Fixtures/audio/long-dictation.wav in real time through HoldPipeline with real whisper and the configured gateway inserts text and records release-to-insert ms in build/latency.json; skipped unless DICTATION_LATENCY_BENCH=1.
